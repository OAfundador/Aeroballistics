# Architecture

Why the code is split this way, and where to add things.

## Layers

```
                     ┌───────────────────────────────────┐
   interfaces  ───▶  │  aero (Aerodynamics) · cli        │   simulators and command line
                     ├───────────────────────────────────┤
   optional    ───▶  │  conventions · units · mass ·     │   change the presentation, the inputs
                     │  corrections                      │   or the outputs, only when asked for
                     ├───────────────────────────────────┤
   canonical   ───▶  │  core · data  (+ program)         │   the 1973 program
                     └───────────────────────────────────┘
```

Dependencies only point downward: the additions import from the core, and the core imports none of the additions. With no options, `aeroballistics.Aerodynamics(p)` is the canonical table interpolated in Mach, and the command line opens its output with `Mode: canonical (1973 SPIN-73)`.

## The package, module by module

| Module | Role | Depends on | Layer |
|---|---|---|---|
| `core` | the equations, `table()`, `stability()`, `format_table()`, `geometry_warnings()`, the `Projectile` card and `M437` | `data` | canonical |
| `data/` | the `DATA` blocks XA … XG; each `x?_read.py` keeps the reading, the decided cells and the evidence | — | canonical |
| `program` | the original program described as objects (`SPIN73`); generates `docs/ORIGINAL_PROGRAM.md` | `core` | documentation |
| `conventions` | report convention ↔ modern convention (exact conversion) | — | addition |
| `units` | inputs in mm, g, g·cm², °C, CG from the base (exact conversion) | `core` | addition |
| `mass` | estimate of the CG, mass and inertias missing from the card | `core` | addition |
| `corrections/` | the `Correction` interface, the registry by name, `finalize` (recomputes the derived columns) and the `free_flight` correction, which only reads the JSON generated by the fit | `core` | addition |
| `aero` | `Aerodynamics`: applies corrections and convention and interpolates in Mach | `core`, `conventions`, `corrections` | interface |
| `cli` | the `aeroballistics` command | all | interface |

## One computation, from the card to the simulator

```
inputs                   canonical                    outputs (optional)             query
─────────────────────    ──────────────────────────   ────────────────────────────   ─────────────────────
units → Projectile   ─▶  core.table(p)             ─▶ corrections → finalize      ─▶ convention → Mach
mass (if missing)        17 Mach × every column       (CPN, CPF, CX2, stability)     Aerodynamics(mach)
```

`units` and `mass` act **before** the program, on the inputs; `corrections` acts **after**, on the outputs. A correction never has to maintain the derived columns: `finalize` recomputes them after all of them.

## The repository

```
src/aeroballistics/ the package (above)
tests/             the suite: python -m pytest (adaptation, 1973 tables, library, additions)
scripts/
  paths.py         the repository paths; puts src/ and the script folders on sys.path
  adaptation/      how each DATA was decided: per-block analyses, reading and checking of the
                   1973 tables, circularity and error_comparison.py (VERIFICATION.md)
  free_flight/     SPIN-73 against measurements: benchmarks/, correction/ (generates the
                   correction JSON), mr1833/ (7.62 NATO) and hitchcock/ (BRL 620)
  mass/            the validation of the mass estimate (MASS.md)
  reading/         reading of the scan and the PDFs: crops, PDF pages, JBIG2 decoder
examples/          runnable examples (examples/README.md) and input cards in inputs/
data/
  tables_1973/     the report's 13 output tables, transcribed; readings/ has the raw reading
  free_flight/     free-flight measurements, round by round, in each source's convention
docs/              transcription notes, the original program, verification, library, mass,
                   free_flight/ and results/ (reference outputs of the scripts)
output/            what the scripts and the examples write (outside Git)
sources/           PDFs and the scan (outside Git; see sources/README.md)
```

## What the structure protects

- **The canonical output does not change by accident.** Everything that alters results lives outside the core and only comes in when asked for.
- **Nothing decided validates itself.** `scripts/adaptation/circularity.py` reads the decisions recorded in `aeroballistics.data.x?_read`, in `data_cna.py` and in the `decide:` lines of the table CSVs, and flags the circular cells. They stay out of the statistics of the tests and of the verification.
- **Data kept apart from code.** The 1973 tables and the measurements live in `data/`, as CSV with the provenance in the header. Scripts and tests find them through `scripts/paths.py` (the tests, via `tests/conftest.py`).
- **Everything runs from a clone, without installing.** Each script starts by putting `scripts/` on `sys.path` and importing `paths`; the examples use `examples/_bootstrap.py`. With `pip install -e .`, those paths are just redundant.

## Where to add things

- **A new correction:** a class with `name` and `apply(t, p, ctx)` ([LIBRARY.md](LIBRARY.md)), registered with `aeroballistics.corrections.register` so it can be called by name. If it is fitted to data, the fit lives in `scripts/` and the result in a file the library only reads, like `corrections/free_flight.json`.
- **A free-flight measurement:** a CSV in `data/free_flight/`, with the source's conventions in the header; the loader in `scripts/free_flight/correction/flight_data.py`; the test in `tests/`.
- **A rereading of a `DATA` block:** in the block's `src/aeroballistics/data/x?_read.py`, with its class (verified, decided by the model or pending) and the evidence. If it is decided by some table, record that in the structures `circularity.py` reads (`DECIDED`, `CORRECTIONS`, `RECOVERED`) and check that the cells used leave the validation.
- **A reread 1973 table:** the raw reading in `data/tables_1973/readings/`, the CSV generated by `scripts/adaptation/resolve_glyphs.py` and checked, without the model, by `scripts/adaptation/check_identities.py`.
